# 路线图与当前边界

方向是稳定执行已有任务和改善共通结构。以下是维护方向，不是交付日期或功能承诺。

## 当前具备

单窗口多账号、独立 Worker 和日志；主城与城外队伍监控；按配置指令调度武勋；按游戏实际奖励次数参与讨贼；多阶段铺路；城内寻找农田与低粮恢复；独立日常开关；诊断导出和完整包校验。

## 优先完善

| 方向 | 需要的证据或工作 |
|---|---|
| 连续执行稳定性 | 更长的真实运行，明确异常出口、恢复和重复操作情况 |
| 铺路实战恢复 | 补给下降、遇敌及被击退后的真实样本与恢复策略 |
| 识别泛化 | 不同渠道、赛季前期、少队伍和不同阵容布局的脱敏复现 |
| 安装与迁移 | 新电脑、不同 MuMu 安装位置和 Windows 环境验证 |
| 调度效率 | 减少重复导航与读取，同时保留当前实例和队伍核对 |

## 已知限制

- 基线为 Windows 10/11 x64、Windows MuMu 5.30.1.3586、简体中文 1920×1080。其他 16:9 尺寸有缩放处理，不能据此保证所有布局兼容。
- 铺路的实战补给下降、遇敌路线重选与击退恢复尚未实现；没有自动换队接力。
- 亲卫自动出征和铺路未开放。不会购买、续费、发送频道消息或自动转换资源地。
- 停止助手只停止新输入，已经由游戏接受的行动不会撤销。
- 离线测试、一次实机成功与长期无人值守是不同的验证范围。

如果某个问题影响持续使用，请通过 Issue 给出脱敏后的复现，不要把某一账号的坐标、额度或截图外观当作通用规则。
