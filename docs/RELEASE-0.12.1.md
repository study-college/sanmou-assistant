# 三谋助手 0.12.1

2026-11-24 · Windows x64

## 这次更新

本版聚焦 **拉线与巡检执行效率提速** 以及 **出征补兵与镜头切换稳健性修复**，来自实机连续挂机复盘：

### 一、截屏与识别提速
- **ADB 原始帧截屏提速**：默认改用 Android 原始 RGBA8888 帧（`screencap`），省去模拟器端 PNG 压缩耗时，单次截屏明显提速；遇不兼容设备时自动回退 PNG 并在本会话记住。
- **高频页面识别提速**：寻访徽章清晰在位时直接判沙盘/内城，出征页、地图沙盘与部队页等一级页面前置判定，避免每次读页都触发全宽强敌预警 OCR 扫描。
- **MuMu 5 实例就绪兼容**：兼容 `player_state="start_finished"` 且 `adb_port` 已就绪的状态，减少模拟器运行中偶发误报「尚未启动」。

### 二、拉线出征补兵与形近字修复
- **选队后立即重截核对**：修复进入出征页默认选中满兵队时，沿用旧图误判「一键补兵」按钮、路线阻挡或「自动征兵」勾选的问题。
- **补兵达标即直接放行**：一键补兵后优先核对实际兵力是否达到出击下限；只要已达标，即使顺手抽干区块配额归零也会直接出征，不再误判「补不动」而撤回主城。
- **兼容「证兵」OCR 形近字**：出征页与城外状态识别将「证兵」按「征兵」处理，不再漏判正在征兵的队伍。

### 三、减少无效飞镜头与镜头快路护栏
- **等待态与城外可派队不再乱飞镜头**：拉线等待态（行军/调动/撤退/重伤/战斗/驻守/委托）即使清了兵力缓存也不再飞镜头读队；已知满兵上限且开启一键补兵的城外可派队直接奔赴目标出征页，同轮多队自动复用镜头快路；刚回主城本轮已完整读队时不再重复读第 2 遍；铺路进行中按整帧右侧角标原地等待，不飞镜头。
- **镜头快路安全护栏**：`view_on` 增加 45 秒有效期、轮间等待自动清空，且禁止对自己主城走点击屏幕中心快路；若点中心意外进入城内或非沙盘页面，自动安全退回沙盘再走标准坐标定位，不再卡住整轮。
- **缩放复用已有沙盘帧**：`zoom_out_to_map` 复用已持有的干净沙盘画面，减少重复截屏与识页。
