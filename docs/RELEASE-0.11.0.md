# 三谋助手 0.11.0

发布日期：2026-11-14

> 本版已于 **2026-11-14 正式发布**。源码、Windows 完整包与 SHA256 校验文件见 [v0.11.0 Release](https://github.com/study-college/sanmou-assistant/releases/tag/v0.11.0)。

## 概述

0.11.0 是一版以识别性能与稳定性为主的源码小版本：不换 OCR 模型、不新增依赖，把页型识别的 OCR 调用改为帧内有界区域共享，并把部队角标的模板计算与批量读取整体提速；同时收尾两份独立复核提出的修复。刷武勋、讨贼、自动铺路、拉线与日常等既有功能逻辑未做改动。本轮不含实机验证。

## 主要变化

### 页型 OCR 调用管线优化

- 页型识别改为在帧内按检测区域建立有界共享：重叠区域不重复 OCR；顶部左右标题叠图一次识别后映射回原坐标；底栏复用、出征页强证据早退。
- 模态、断线、聊天与渠道浮窗的识别优先级保留；黄色出征按钮仅作快速通道，灰色出征按钮仍走完整判定，行为不变。
- 同帧样本对比（OCR 调用次数 / 耗时）：
  - 沙盘 A：15 次 / 3.183s → 8 次 / 2.493s
  - 沙盘 B：15 次 / 4.430s → 8 次 / 1.875s
  - 出征：14 次 / 1.522s → 9 次 / 1.185s
  - 寻访：10 次 / 1.137s → 6 次 / 0.887s
  - 四个样本耗时下降约 22%–58%。

### 角标模板预处理与批量读取

- 角标模板掩罩的向量与范数移到加载期预计算；`read_slots(image, slots)` 共享每帧 HUD 确认与图像转换；`read()` 与 `read_slot()` 结果契约不变，`Game` 优先批量读取并兼容旧 reader。
- 同一组 12 张校准帧：中位 0.8419 → 0.1575 秒/帧，约 **5.35 倍**提速。
- 准确性：子任务 22 帧优化前后状态零差异，45/45 标注槽正确；黑帧与噪声仍判 unknown，同帧重伤判断与建筑内队伍左移的既有规则不变。

## 问题修复（两份独立复核的收尾）

- 整帧角标读取 `read_all_marker_states` 重新抛出 `Stopped` 与 `TransportUnavailable`：断连不再被异常兜底吞掉，停止/暂停请求原样传播。
- 少队时出征卡按真实位置居中：`deployment_strength` 支持 `center_x`，兵力按卡中心读取。
- 未拥有的拉线队不再参与 remaining 结束判定，不会阻止其余队伍收尾。
- UI 错误提示与既有 ERROR 日志去重，不再重复上报同一问题。
- `AccountStore.get` 对不存在的账号显式抛出 `ValueError`。
- 主城 `auto_refill=False` 是用户有意保留的策略：仅补充说明，行为不变。
- release/verify 默认 tag 同步为 v0.10.0，`AGENTS.md` 纳入 CI 路径。
- 诊断安全/完整两种模式以合成数据复核：安全 ZIP 仅含报告与 HTML、无原始消息；完整 ZIP 仅在显式 `--include-private` 后生成。

## 升级说明

- 本轮不改变配置格式，无需迁移；直接替换程序目录即可，`data/` 中的账号、配置、会话与数据库保留不动。
- 建议升级前停止运行中的任务，并备份 `data/` 目录。

- 运行时自检（runtime）：Qt / OpenCV / ONNX / OCR 加载与数值样本识别通过。

- 源码审计：88 项检查，0 问题。
- 诊断导出：合成数据复核安全/完整两种 ZIP 的边界如上。

## 已知限制与边界

- **未实机**：本轮未连接模拟器、未操作真实游戏、未修改真实账号配置；不宣称实机长期无人值守验收。
- 未更换 RapidOCR 或模型，未引入 GPU 或新依赖；57 个既有 skip 未消除，旧 merit 契约测试仍有覆盖缺口。
- OCR 数字 0 目前只有桩测试；本轮未新增真实零额度帧样本。
- 上述性能数字为离线小样本同帧对比，不代表所有账号、赛季布局或长期实机收益。
- 异常钩子、停止等待、事件文件滚动与大型结构拆分不在本轮完成范围。
