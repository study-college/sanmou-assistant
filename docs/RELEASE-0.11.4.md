# 三谋助手 0.11.4

2026-11-16 · Windows x64

## 变化

- 修正空闲队因头像亮块被显示为「待识别」，以及建筑界面内撤退角标被读偏的问题。
- 整批、单队和铺路／拉线读取用同一张图上的头像文字判断重伤。调动停留时出现「重伤」也会等待恢复。倒计时结束后仍以现场读数为准。
- 新增「攻城调动」独立图标。前往攻城大营时按移动状态处理，图标显示为「攻城调动」。其他未登记图样继续显示「待识别」。
- 铺路出征出现「本次出征中铺路地块将消耗体力」时，识别确认控件及「今日登录不再提示」，按现有铺路流程继续。

## 下载和检查

[GitHub Release v0.11.4](https://github.com/study-college/sanmou-assistant/releases/tag/v0.11.4) 提供 Windows x64 完整 ZIP 和 SHA256 文件。解压后可运行包内的完整性校验脚本。安装和配置迁移见 [使用说明](09-user-guide.md)。

## 验证范围

角标验收使用留存的真实画面和现有任务测试。建筑内「调动停留＋重伤」的行为由用户确认，并用任务入口检查出征判断。实机连续运行和实际出征的验证以真实游戏会话为准。
