# 三谋助手 0.11.1

发布日期：2026-11-14

## 概述

0.11.1 是一版以交互体验与读取调度为主的源码小版本：任务设置新增“空闲”状态并与“隐藏”明确区分，六类可调整表格统一列宽记忆，移除口径不明的“本次铺路”汇总，个人主页武勋读取限定在刷武勋或拉线实际启用时，阵容名在同一次任务运行内只读一次并缓存，同帧角标改为先整帧预发布、再逐队读详情。刷武勋、讨贼、自动铺路、拉线与日常的既有执行逻辑未做改动，铺路坐标与待核对订单仍走原路径。需求依据 `docs/77-next-iteration-ux-2026-11-14.md`。

## 主要变化

### 1. 任务设置新增“空闲”，与“隐藏”明确区分

- 任务单选扩为五项：刷武勋 / 讨贼 / 铺路 / 拉线 / 空闲；未做任何选择的队伍默认按“空闲”处理，不再强迫四选一，也不因未选择而报缺项或拒绝运行。
- 空闲 ≠ 隐藏：隐藏的队伍从运行总览消失并锁定设置；空闲的队伍仍在总览显示，兵力、重伤、体力等状态读数继续随巡检刷新，详情可配置，但不参与任何任务调度、不派单、不下单。
- 切换空闲/隐藏不丢该队已有的目标、补兵点、铺路归属等设置；既有配置中的 merit / bandits / pave / line / hidden 角色原样载入与回写，无需迁移。

### 2. 六类表格列宽记忆

- 运行总览、任务设置表、目标、补兵、拉线、铺路共六张可调整表格统一列宽记忆：拖动结束防抖 400ms 写入 `data/ui-state.json`，重开后按保存值恢复，不会每拖动一像素就写盘。
- 记忆口径为全应用统一，不按账号另造文件；没有记录、记录损坏或列数变化时回退当前默认列宽，且只回退该表，其他表的记录与分栏状态不受影响。
- 默认列宽与现版一致；只记忆列宽，不改变表格内容、列顺序、列语义与数据来源。

### 3. 移除“本次铺路”汇总，逐队进度完整保留

- 运行总览右上角不再显示口径不明的跨队“本次铺路”汇总数字；移除的只是展示，不触碰铺路状态机。
- 逐队逐点进度完整保留：总览行内进度（如“铺路 2/5”）、实时日志与状态栏按事件报告的本路线进度照常显示。
- 铺路提交、到达、未知提交恢复、低粮暂停新出征、重伤/返回恢复与订单持久记录逻辑不变。

### 4. 武勋读取限定在刷武勋或拉线实际启用时

- 个人主页武勋只在本次实际存在刷武勋或拉线队时读取；纯讨贼、纯铺路、纯日常的运行路径不再进入个人主页读取。“实际启用”以任务设置当前生效状态为准，并按实际拥有的槽位过滤，未拥有槽位上的配置不触发读取。
- 低粮补给仍只跟随刷武勋：拉线队在场会读武勋（仅展示），但不因此打开低粮门槛；讨贼低粮停新讨贼、铺路低粮暂停新出征等行为不变，粮食账号共享库存与补给记账规则不变。
- 刷武勋或拉线启用时，按现行流程的读取、证据记录与受理重提规则不缩水，读数有效期等约束不放宽。

### 5. 阵容名同一次任务运行只读一次并缓存

- 阵容名在同一账号、同一队伍、同一次任务运行内只读一次并缓存，缓存挂在 Game 实例上（键为队伍键）：换队、换账号、新任务运行各自独立，不跨实例复用，任务结束随实例丢弃。
- 首次读不到名字时不缓存空值；后续识别失败时回填最近一次阵容名，UI 已显示的阵容不被抹掉；实际读得到新阵容名时照常更新缓存。
- 缓存只针对阵容名，不省 OCR：名称来自详情/总览英雄区的同一次 OCR 跨度过滤，不额外跑识别；兵力、体力、补给、重伤、角标等动态字段仍每次现场重读，作为主城兵力下限、重伤、体力、补给等出击门槛依据，读不到保持未知，不以缓存凑数。

### 6. 同帧角标先整帧预发布，再逐队读详情

- 整帧角标读取成功后，先把所有实际存在且未隐藏的队伍（含本批之外的铺路、拉线、空闲队）连同角标状态、同帧时间与缓存阵容整帧预发布给界面，再对需要详情的队逐队读取；详情完成后整帧替换预发布帧，忙碌、行军、驻守等队本轮免详情扫描的既有逻辑不变。
- 预发布只进 UI，绝不进入 decide：派兵决策只消费详情/批处理观测，预发布不减少任何导航/OCR，也不改变派兵顺序。
- needs_scan 每队只计算一次：到点复核（recheck_due）有记账副作用，预发布与批处理共用同一份结果，避免重复计算把到点复核队误判为免读而丢掉强制开详情。
- 铺路坐标与待核对订单走原路径：预发布不触碰铺路推进与订单持久记录；详情读取失败回退观测时，未知状态仍不结清待核对订单，强制复核日志照常。

## 升级说明

- 本轮不改变配置格式，无需迁移；老配置角色原样载入，`ui-state.json` 新增列宽记录，无记录时各表保持默认布局。直接替换程序目录即可，`data/` 中的账号、配置、会话与数据库保留不动。
- 建议升级前停止运行中的任务，并备份 `data/` 目录。
