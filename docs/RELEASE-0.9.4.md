# 三谋助手 0.9.4

2026-11-10 · Windows x64 · 铺路可视化与抗干扰小版本。

## 本版改动

- **铺路进度常驻显示**：运行总览新增“本次铺路 ?/?”指标；铺路队伍那一行的
  “下一步/等待原因”常驻显示“铺路 12/17 · 下一点 (80,494)”，完成时显示
  “铺路完成 17/17”。状态栏仍会显示当前动作，但不再依赖它看进度；完整过程继续写日志。
- **进度事件统一**：`Worker.pave_event` 输出 `done/total/status/next`，界面根据事件刷新；
  铺路开始时清零，下一轮任务重新计数。
- **已识别弹层自愈**：巡检遇到暂未识别页面时，先调用
  `ensure_sandbox(recover_navigation=True)` 尝试关闭月卡/月卡结果、活动/福利/寻访、聊天、
  渠道浮窗、战情摘要、普通弹层等已识别窗口，再等待重读。跨天出现的月卡领取标志/弹层
  不会卡住铺路。
  - 只关闭，不自动领取月卡、不点购买/续费、不改日常开关；月卡领取标志本身不点击。
  - 异地登录、维护、持续设备错误仍按原规则停止，不吞掉。
- **测试**：`tests/test_pave.py` 增加进度事件回归（`next` 指向下一点、完成后为空）。
