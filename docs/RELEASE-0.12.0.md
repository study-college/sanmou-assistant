# 三谋助手 0.12.0

2026-11-23 · Windows x64

## 这次更新

### 一、运行中热换坐标与双端（人 / Agent）控制接口
- **挂机途中直接换坐标，不用停止重启**：运行总览新增 **「切换目标坐标」** 一键弹窗、**「暂停 / 继续任务」** 按钮与实时 **「当前目标」** 摘要条；`03 目标与铺路` 里的「武勋目标」和「拉线目标」两个标签页在运行中保持可编辑，点底部 **「热应用目标设置」** 立即生效。换坐标后直接唤醒下一轮按新坐标出击，跳过连接、主城核对、部队列表与隐藏显示检查；已在旧目标行军或驻守的队伍自然结束后再转，不撤军、不丢待核对订单。
- **面向 AI（Agent）的运行时控制体系**：内置仅限本机 `127.0.0.1` + 随机 Bearer Token 鉴权的本地控制服务，配套统一纯 JSON CLI（`sanmou-assistant ctl ...`），支持 **GUI 人机同屏协同**（桌面窗口自动开启服务，人机双向实时同步不互相覆盖）与 **无头后台托管**（`--command serve`）两种模式。支持实时查状态、热切拉线/武勋目标、热换备用征兵点、启停/暂停/恢复/立即唤醒与日志查询；控制服务未运行时，目标和征兵点命令自动离线校验落盘。详见 [Agent 指南](AGENT-GUIDE.md)。

### 二、自 0.11.5 以来的持续运行与稳定性修复
- **拉线多目标自动退让与兵力自动复拉**：拉线不再只盯第一个目标死磕——遇到保护状态、无连接地或目标被建筑模型遮挡点不中时，自动冷却并立即尝试下一个启用目标；因缺兵收尾的拉线队每 5 分钟自动复核兵力，恢复到出击线后自动复拉，无需重启。
- **修复拉线旧兵力缓存与镜头定位卡死**：修复回城补满后沿用旧兵力缓存导致的假低兵循环；引入显式镜头现场状态，读队/缩放/拖图/出城后自动作废旧坐标上下文，避免派兵时误点本队或城池卡住。
- **隐藏显示 7 项全勾选**：任务启动打开隐藏时，自动展开面板逐项核对勾选全部 7 项隐藏选项（部队模型/名字、行军线、建筑名字、战术指令、同盟计划、最低视角自动触发），减少地图信息遮挡识别。
- **消除选中行拆字自锁与无主铺路订单卡队**：部队总览支持同行碎片合并与缺行按槽位等距点选，读取异常必回沙盘；取消或修改铺路路线后遗留的待核对铺路订单会自动按现场结清，不再锁死整支队伍。
- **签到与里程碑幂等重试**：每日签到与累计进度奖励的待核对状态支持按现场撤销并有限次重试，不再因单次核对失败全天卡死。
- **运行细节加固**：修正暂停态刷新等待、拉线征兵点既有配置保留等边界问题。

下载 [v0.12.0 的 Windows x64 完整包](https://github.com/study-college/sanmou-assistant/releases/tag/v0.12.0)，解压后双击 `启动助手.cmd`。原来的 `data` 目录（账号、配置、运行记录）可以继续使用，建议升级前先退出旧版。包内附带完整性校验脚本，下载页同时提供 SHA256 文件。

本次版本中 2026-11-18～11-21 的稳定性修复均来自真实运行复盘（含实机拉线复拉、多目标退让、7 项隐藏全勾选验证），2026-11-23 的运行中热换坐标与双端控制接口已完成离线自动化回归、UI 渲染与跨进程控制服务验证（未含实机挂机闭环）。程序不改动游戏设置、不撤军，实机连续运行表现以你自己的游戏会话为准，欢迎到 [Issues](https://github.com/study-college/sanmou-assistant/issues) 反馈。
