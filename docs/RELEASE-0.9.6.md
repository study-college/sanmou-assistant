# 三谋助手 0.9.6

2026-11-13 · Windows x64 · 拉线模块与出征弹窗小版本。

## 本版改动

- **新增独立「拉线」任务**：队伍任务新增“拉线”，与“刷武勋”“铺路”并存且互不影响。
  给定一个目标坐标后反复拉：**打赢就地再拉**、**打输由游戏撤回出发点后继续**；
  动作自动选可用（目标点有“攻占”用攻占，否则用“行军”）；目标已被己方占领时
  **继续行军并记一条 WARN**（无战果，按用户选择不拦）。**只在用户手动停止时结束**。
  纯决策函数 `models.line_decision()`；每队一个目标坐标，不做多目标轮换。
- **补兵链路**：出征页出现“一键补兵”且兵力低于本队出击下限才点（主城与营帐/城池
  都可能出现该按钮）；**按钮不存在＝当前补不动**（没辎重 / 范围无辎重 / 兵池不足），
  走兜底而不是当“点了没反应”重试。兜底两选一：**回城免费补兵**（默认，消耗路程）
  或**停手等下一轮**。营帐/城池自然征兵到出击下限后继续拉。区块读数归零判为补不够。
- **弹窗层**：`vision.page()` 新增两类页型，不再落成 `unknown` 卡住提交——
  - `dispatch_confirm`：`部队有未加点的武将，是否继续出征？` /
    `部队未携带满战法，是否继续出征？` → 选“继续出征”。
  - `enemy_warning`：`敌军强盛，请主公三思！` → 先勾选“该等级今日不再提示”，
    等 `继续进攻(N秒)` 灰色倒计时走完再点（**倒计时没走完点了是点空**）。
- **隐藏重核**：游戏进出主城会自动关闭隐藏显示；脚本回到沙盘后**立刻重核一次**
  小眼睛，不再整段运行都在“隐藏已关”的脏画面上识别。
- **按队同步「回城自动补兵」**：界面显示游戏真值；界面改动只标“**待写入**”，
  下一次访问该队详情页时才读当前值→与待写入比→**不同才点**→复读确认后清标记；
  还没读过显示“未知”，不写不猜；外部改动以游戏为准。**不统一开启所有队伍**
  （脆皮打杂队故意不勾，补满就是浪费兵力）。
- **不改变既有行为**：刷武勋（`merit`）与铺路（`pave`）逻辑未改动；没有拉线队伍时
  行为与上一版一致。
