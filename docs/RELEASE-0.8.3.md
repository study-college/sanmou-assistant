# 三谋助手 0.8.3

2026-11-03 · Windows x64 · 依赖安全修订版。

Pillow 更新至13.0.0、pytest至9.0.3、Markdown至3.8.1，修复公开后的依赖扫描发现的已知漏洞；游戏调度逻辑保持0.8.1的实现。

## 安装与兼容性

程序版仍自带运行环境，完整解压后运行 `启动助手.cmd`，不需要另外安装Python。源码和构建最低要求改为标准CPython3.11，支持3.11–3.12 x64。旧3.10虚拟环境不能直接沿用；保留原环境备份，用新的标准Python创建隔离环境，不覆盖自己的data。

Pillow13已停止支持Python3.10，见[官方说明](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html#python-3-10)。相关依赖安全公告可在仓库Security页面和上游项目查看。

## 包内容和验证

保留MIT许可、第三方说明、完整源码和识别资源、离线使用手册、更新记录、社区说明和发布审计。具体独立测试、源码OCR、Windows构建、压缩包审计、完整下载及打包exe的OCR检查见对应GitHub Actions记录和Release说明。

本版没有新增游戏实机验收，不扩大既有账号、页面或长期运行结论。完整截图、账号配置、数据库、日志和凭据仍留在本机，不进入发布内容。路线边界见[ROADMAP.md](ROADMAP.md)。
