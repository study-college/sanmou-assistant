# 三谋助手 0.8.4

2026-11-04 · Windows x64 · 挂机可观测性与自然征兵闭环小版本。

## 本版改动

- **武勋读数**：点头像进个人信息页读"武勋"累计值，本次任务第一次作基线、之后每 30 分钟一次；运行总览"本次出征"旁新增"本次武勋"（只展示，不参与派兵，读完即用左上返回箭头回沙盘）。
- **自然征兵够兵就回城**：只要兵力达到本队出击下限就回城，不再要求征到满兵；程序以发兵记录和主城坐标为准，**确认回到主城之后**才允许再拉线刷武勋。此前角标在征兵点读到"空闲"会被当成已回家，直接从征兵点出兵。
- **久未产出复核**：角标不可派且 20 分钟没有新动作时，开一次详情读兵力并写日志；不读征兵剩余时间，不推算 ETA。
- **重伤本地倒数**：读到重伤倒计时后本地倒数，到点复核一次再放出，中间不空转开详情。
- **讨贼队不代劳补兵**：兵力不达标且游戏内"主城自动补兵"未开启时跳过讨贼，日志写明原因并每小时提醒一次，脚本不改游戏设置。
- 粮食默认触发库存 50 万、恢复库存 100 万（粮仓容量 600 万，不会溢出）。
- 诊断摘要改为全文件流式计数；界面里手动停止也会写 `result.json`。

## 验证

- `python -m pytest -q`：510 passed, 58 skipped。
- 实机（账号 测试主公，实例 0）：个人信息页读数 501.5万 与界面一致；正常出征/驻守确认；主城 4 队因游戏内自动补兵未开被跳过并写入 WARN。
- 完整的"城外包补→征满→回城→再出击"两小时闭环与 20 分钟复核尚未实跑，由单元测试覆盖；下次真实补兵时会写"已 N 分钟没有新动作（忙碌）；详情：兵力 x/33000"。

## 兼容性

配置与数据库向后兼容，新增 `merit` 事件旧版会忽略；`profile.json` 的 `food_low/food_recover` 若仍是 5 万/50 万，可自行按新默认调整。详见[59](59-merit-and-natural-recruit-0.8.4-2026-11-04.md)。
