# 三谋助手 0.11.5

2026-11-18 · Windows x64

## 这次更新

- **空闲的队伍不会再被当成“待识别”**：主城里空闲的队伍以前有时会一直显示「待识别」，脚本不敢派它出去，只能干等；现在会正常读成「空闲」，该出征的队伍照常出征。
- **新增「委托」**：部队被委托给同盟城主的城池后，头像右下会出现浅蓝色拳套图标，总览显示「委托」。委托期间队伍交给城主管理，脚本不会对它派兵、回城或补兵，也不会去翻它的详情页；想让它继续出战，需要你自己在游戏里解除委托。
- **新增「攻城调动停留」**：攻城调动到达、停在攻城大营的队伍，现在能正确识别并按停留处理，条件满足时可以正常派出。
- **出征提醒一次处理完**：一次出征连续弹出的「确认出征」「本次出征中铺路地块将消耗体力」「补给不足」「武将未加点/战法未携带满」「敌军强盛」等提醒，会按顺序逐个确认，不再把提醒当成陌生画面停下来等。

## 下载和更新

下载 [v0.11.5 的 Windows x64 完整包](https://github.com/study-college/sanmou-assistant/releases/tag/v0.11.5)，解压后双击 `启动助手.cmd`。原来的 `data` 目录（账号、配置、运行记录）可以继续使用，建议升级前先退出旧版。包内附带完整性校验脚本，下载页同时提供 SHA256 文件。

首次使用和页面说明见 [使用说明](09-user-guide.md)。

## 说明

本次更新的判断逻辑来自真实运行中遇到的问题，并用留存画面复现核对；没有改动游戏内设置，也没有替代你在游戏里的操作。实机连续运行的表现以你自己的游戏会话为准，遇到问题欢迎到 [Issues](https://github.com/study-college/sanmou-assistant/issues) 反馈。
