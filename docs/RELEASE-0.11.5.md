# 三谋助手 0.11.5

2026-11-18 · Windows x64

## 变化

- 修正空闲队被长期显示为「待识别」：认不出的画面必须先有角标底板（黑色菱形底板，或金色时钟那种亮色底板）才算“未学过的角标”；没有底板时，头像里的亮块只当人物画面，按「空闲」处理。此前一队（周泰/邓艾/太史慈）在主城空闲时，头像左下的披膊亮块被当成角标，整局不派兵也不复核。
- 新增「委托」角标（浅蓝色拳套）。部队被委托给同盟城主的城池后由城主管理，脚本不再对它派兵、回城、补兵，也不为它打开详情页；总览显示「委托」。
- 出征提醒整修：一次出征可以接连出现二次确认、铺路体力提示、补给提示、加点/战法提示和强敌预警，提交后与角标复核前后都按识别到的页型逐层处理并重新截图，不再把提醒当成未知页卡住。补给提醒与体力提示共用同一套勾选与确认口径，读不清时只留证、不改点其他位置。
