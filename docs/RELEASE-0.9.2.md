# 三谋助手 0.9.2

2026-11-09 · Windows x64 · 队伍读取与页码解耦（源码修复；本版尚未打包发布）。

## 本版改动

- **根因**：队伍读取入口 `main_portraits` 依赖 `portrait_pager_present`，在固定屏幕区域
  `x1770-1910, y855-885` 数近白像素；3 队时该区域是地图，事故帧数到 360 个近白像素
  （阈值 30），被当成“有分页条但页码读不出”，三队各重试 3 次后全部拒绝读取。
- **删除页码概念**：移除 `Game.main_portraits`、`Vision.portrait_page`、
  `Vision._portrait_page_at`、`Vision.portrait_pager_present`。沙盘页型不再读队伍页码，
  只由底栏“武将/同盟/职业”与顶部“繁荣/道路”确认。
- **新的队伍入口**：`Game.open_team_page(slot)` 只点本队头像进入部队页/总览；进入后按
  游戏自己的“部队一/二/…”行和选中高亮核对身份，再读详情。点错头像不会把别的队数据
  当成本队。
- **失败隔离**：入口失败只影响该队本轮，其他队继续；不再出现同一帧三队×3 次的必然失败。
- **城外读取**：单队总览读取也先按槽位选中行再读数据，与批量读取保持一致。

## 兼容性

- 当前赛季没有亲卫队，2~5 支主队只有一页；本版按这个真实布局工作。
- 如果未来恢复亲卫队/第二页：本版不会再去猜页码，但也不支持从第二页切回主队页；
  届时需要用“部队行选槽位”的结构方式重新实机校准，不能再引入颜色判据。
- 本次只改源码，未重新打包；发行包需重新构建后再分发。
