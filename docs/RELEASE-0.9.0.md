# 三谋助手 0.9.0

2026-11-06 · Windows x64 · 界面与交互改版，游戏调度逻辑不变。

## 本版改动

- **应用图标**：深墨蓝底、金色行楷“谋”与朱红印章，打包 exe 与任务栏统一显示；源码运行时也设置独立应用标识。
- **窗口自适应**：按屏幕可用区域布局，最低支持 1366×768 与 100%/125%/150% 缩放；运行总览改为可拖拽分区（队伍表 / 游戏画面 / 实时日志），分区比例保存在本机。
- **运行总览**：每队前置显示开关，取消勾选即退出全部任务且不再读取；底部提供“已隐藏 N 队”恢复入口。
- **每队单一任务**：部队任务页每队只有刷武勋、讨贼、铺路三个单选；删除“铺路路线”“优先任务”“目标组/备用点”平铺列，改为行内“详情”配置目标组与有序补兵点；选“铺路”时再挑路线。
- **铺路路线**：不再有“启用”勾选，只有被队伍选中的路线才执行，未分配的路线不会拦开始执行。
- **地址输入**：主城、武勋目标、补兵点、铺路路线都支持粘贴游戏分享地址即时识别添加。
- **文案收敛**：全站改为渐进式披露，页面只保留一句目的与现场状态，规则和限制收进“▸ 说明”。
- **导航精简**：左侧由 8 页收敛为 6 页——运行总览 / 部队任务 / 目标与铺路 / 补兵与日常 / 连接与配置 / 日志与诊断。

## 自 0.8.3 以来的其他改动

- 武勋读数：点头像进个人信息页读累计值，本次任务首次作基线，之后每 30 分钟一次，“运行总览”展示“本次武勋”，只展示不参与派兵。
- 自然征兵够兵就回城：兵力达到本队出击下限即回城，确认回到主城之后才允许再拉线刷武勋。
- 久未产出复核：角标不可派且 20 分钟没有新动作时，开一次详情读兵力并写日志，不推算 ETA。
- 重伤本地倒数、讨贼队不代劳补兵、粮食默认 50 万/100 万触发与恢复、诊断摘要改为全文件流式计数。

## 验证

- `python -m pytest -q`：513 passed, 58 skipped（本机隔离环境 CPython 3.11.15）。
- 本轮只改界面与交互，调度、派兵、铺路与讨贼判定沿用 0.8.x 已验收实现，没有新增游戏实机长跑；界面改版也没有扩大对账号、页面或长期无人值守的证明范围。
- Windows 完整包由 GitHub Actions 构建：源码 OCR、独立测试、逐文件清单与 SHA256、ZIP 与历史审计在同一次运行中完成；发布后由 `Verify Windows release` 完整下载并运行打包 exe 的 OCR 检查。

## 兼容性

- 配置与数据库向后兼容。旧配置里的 `merit`/`bandits`/`priority`/`backup` 在加载时一次性转换为单一任务角色，已启用铺路路线会归还给原队伍；转换后不再回写旧字段。
- 升级前停止助手并备份自己的 `data/`，不要用空白数据覆盖已有配置。
- 程序版自带运行环境；源码与构建要求标准 CPython 3.11–3.12 x64。
