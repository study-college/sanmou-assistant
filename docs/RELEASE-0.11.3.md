# 三谋助手 0.11.3

发布日期：2026-11-15

## 概述

0.11.3 是一版以**执行策略与交互**为主的小版本，来自使用者 2026-11-15 按通俗流程图审阅行为后提出的整修要求：粮食恢复不该管铺路和拉线、自动屯田应当独立、拉线收尾不该停掉整个程序、武勋读数显示错误、备用征兵点应随功能拆开、选中地块后页面不该判成未知、加载与云雾等待过长、坐标入口应统一为“粘贴识别并添加”。

本版只改这些被明确指出的地方，刷武勋、讨贼、自动铺路、拉线与日常的**既有执行主流程**（派兵、核对、订单、回城、补兵）没有重做；离线全量回归 756 项通过、57 项既有跳过、0 失败。本轮未连接模拟器、未操作真实游戏。

## 主要变化

### 1. 粮食恢复只约束刷武勋

- 库存低于触发线时，只暂停**刷武勋的新出征**和**备用调动**；铺路、拉线、讨贼、日常不再因为粮食低而停下。
- 没有刷武勋队时不会自动屯田，也不会置位“粮食恢复中”；该标记不再影响其他模块。
- “回城”和三支补兵闭环不受粮食恢复拦截。

### 2. 自动屯田独立成入口

- 手动“检查 / 执行屯田”不再要求配置了刷武勋队，可直接执行。
- 后台自动补粮仍只跟随刷武勋（本版不接入拉线或其他功能），恢复期仍屯到恢复库存。

### 3. 拉线结束只结束拉线模块

- 所有（本赛季实际拥有的）拉线队发出最后一次调动令后，状态栏写“拉线模块已结束，其他任务继续 · 所有拉线队已发出调动令（补兵点）”，刷武勋、讨贼、铺路、日常继续运行；不再停止整个程序。
- 未拥有的拉线槽位仍不参与“还有谁没完成”的判定。

### 4. 武勋读数与展示

- 展示换算把“万”当作 1000，导致 152000 显示成“152.0 万”；改为 10000，正常显示“15.2 万（约 +0.1）”。
- 个人信息页武勋改为整行读取并用「武」标签锚定（「勋」常被 OCR 识别成「助」）：数字必须是唯一候选、位于标签右侧、同一行（纵向重叠 ≥40%），否则按“未读到”处理，不猜数字。武勋仍只用于展示，不参与派兵。

### 5. 界面与备用征兵点重组

- 导航第 4 项改为“**04 屯田和日常**”，页内为“屯田与粮食 / 每日任务”。
- 新增两个配置字段，旧配置自动迁移、保存后不再写旧字段：
  - `merit_backup`：武勋备用征兵点，所有刷武勋队共用，在“目标与铺路 → 武勋目标”填写；
  - `line_backups`：拉线征兵点，按 `main:槽位` 每队一个，在“目标与铺路 → 拉线目标”填写；允许多队填同一个点。
- “部队任务”删除“目标组 / 补兵点”列（9 列），修掉“在拉线里填了补兵点导致刷武勋无法启动”的配置冲突；“详情”只保留拉线队“拉不动时”的回退方式。
- 两张目标表去掉“目标组”列；刷武勋不再按组过滤目标，拉线目标也不再看组。

### 6. 选中地块/建筑的页面不再卡成未知

- 沙盘底栏判定允许 OCR 把“职业/征战”拆成单个字（“业”“战”）。
- 新增“地块菜单 + 底栏 + 寻访徽记”的兜底判定：只有其他页型都认不出来时才把当前画面当沙盘，渠道福利浮窗、城内建筑抽屉等有自己证据的页面不会被误吞。
- 真帧对照：同一张“选中地块”截图，旧口径 17.15 秒判未知并进入重试循环，本版约 2.1–4.5 秒正确判为沙盘。

### 7. 等待提速

- 云雾过渡与切页重截间隔 0.6–0.8 秒 → 0.25 秒；未知页轮询 1.1 秒 → 0.35 秒；等待路径不再重复做高精度复核。
- 页面暂时认不出来时，只做**一次**地图往返拖动（不点击）尝试取消选中，每步手势后重新判读；仍认不清才用缩放按钮和等待。云雾/切页必须读清才继续；异地登录、服务器维护与设备错误仍然留证停止。

### 8. 坐标输入统一“粘贴识别并添加”

- 所有坐标入口（铺路路线、武勋/拉线目标行、武勋备用征兵点、拉线征兵点、主城地址、批量粘贴点）右侧按钮统一读取系统剪贴板中的游戏分享地址；剪贴板识别不出时才用输入框现有文字。
- 普通 Ctrl+V 只做文本粘贴，不再自动识别；剪贴板访问收敛到可替换入口，测试不再依赖使用者真实剪贴板。

### 9. 重伤倒计时

- 运行总览恢复显示“等待重伤结束（约 N 秒）”；倒计时到零显示“重伤计时已到，等待现场复核”，不直接当成已恢复。

## 升级说明

- **配置自动迁移**：旧配置里的全局备用征兵点表与队伍“目标组/补兵点顺序”会按“原来在用的地址”迁到武勋共用点与各拉线队征兵点，不会丢地址；保存一次后只写新字段，再读写结果一致。
- 旧版把“万”当 1000 的历史读数不落库，不需要订正；升级后新读数按正确换算显示。
- 建议升级前停止任务并备份 `data/`。
