# 三谋助手 0.10.0

发布日期：2026-11-13

## 概述

0.10.0 是拉线任务的首个可用版本。本版补齐了拉线任务的收尾流程，重做主城状态判定与沙盘页面识别，并将地图缩放方式由双指手势改为界面按钮。刷武勋、讨贼、自动铺路、日常与屯田等既有功能未做改动。

## 主要变化

### 拉线任务收尾

- 补兵点或一键补兵无法继续补兵时，脚本请求回城。
- 队伍回到主城的瞬间即完成补兵；此后主城征兵只补充兵池，不再为队伍补兵。因此回到主城后首次完整读数仍低于出击线的队伍，判定为无法继续，立即向补兵点发出最后一次调动令，该队任务结束。
- 多支队伍分别收尾：只要仍有拉线队可以补兵与出征，任务继续；所有拉线队均发出调动令后，程序停止，并在状态栏与日志中说明。
- 调动令以出征页提交并确认状态变化为准，脚本不跟踪是否抵达补兵点。
- 已结束的队伍不会自动恢复。

### 主城状态判定

- 主城判定只使用角标：空闲状态没有角标，仅出现在主城；野外停留为绿色箭头角标。坐标不再参与判定。
- 新增无角标防抖：若上一帧为行军、调动、撤退、战斗或忙碌，而当前帧显示无角标，则重新截取一帧；连续两帧一致才判定为空闲。
- 该改动修复了队伍抵达目标或进入战斗的瞬间被误判为已回主城、进而触发错误调动的问题。

### 沙盘页面识别

- 沙盘页型判据不再使用顶部资源栏。顶部为半透明地图，地图标签会覆盖资源文字，导致 OCR 误读。
- 现以底栏“武将/同盟/职业/征战”与右下角“寻访”徽记共同判定。
- 页面连续无法识别时，脚本会尝试使用已识别的地图缩小按钮退回沙盘，不再原地等待。

### 地图缩放

- 地图缩放由双指手势改为左下角缩小/放大按钮长按；按钮位置固定，识别到才点击。
- 坐标定位、从地图沙盘返回沙盘、未知页面恢复均使用该方式；双指缩放在按钮无法识别时作为后备。

## 问题修复

- 修复停止或暂停请求被整帧角标读取的异常兜底吞掉的问题。
- 修复回城日志将“补不动回城”误写为“满兵返回主城”的问题。

## 升级说明

- 直接替换程序目录即可，`data/` 中的账号、配置、会话与数据库保留不动。
- 本版不改变配置格式，无需迁移。
- 建议升级前停止运行中的任务，并备份 `data/` 目录。

## 验证范围

- 自动化测试：580 通过，57 跳过，0 失败。
- 实机：单一账号、单一目标点，完成“自补兵点出发—交战—撤退—回城—补兵—收尾”的完整闭环；地图缩放与沙盘识别在同一会话中反复使用。
- 未覆盖：多支队伍同时收尾（仅单元测试）、其他账号与赛季布局、长时间无人值守。

## 已知限制

- 角标在极少数情况下可能连续两帧缺失，此时仍可能误判为空闲。
- 更换武将或外观后，头像模板匹配可能需要重新校准。
- 粮食不足时补兵会很快停止，拉线任务将提前收尾。
