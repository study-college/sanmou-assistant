# 三谋助手 0.8.2

2026-11-03 · Windows x64 · 公开发行与文档完善版。

游戏功能沿用 0.8.1，本版主要补齐公开协作、隐私检查和发行材料。

## 包含内容

- 原创代码与文档的 MIT License，第三方依赖及游戏识别资源的权利说明。
- 项目首页、使用说明、更新记录、路线图、安全政策和贡献指南。
- 独立测试、提交历史和发布文件审计；公开仓库中的问题反馈与 PR 模板。
- Windows 完整程序、同版本源码、识别资源、离线手册、第三方许可、逐文件清单和 ZIP SHA256。

没有携带维护者账号配置、完整游戏截图、数据库、日志或登录凭据。程序运行后在使用者自己的 `data/` 保存资料。

## 使用

从 Releases 下载 `Windows-x64-full.zip` 并完整解压，运行根目录 `启动助手.cmd`。首次使用先发现自己的 MuMu 实例、匹配游戏渠道、校验本人账号和主城，再运行“只监控”。源码 ZIP 供开发，不是自带运行环境的程序包。

## 验证与限制

具体构建、独立测试、发布审计和下载后 exe 检查见对应 GitHub Actions 记录。0.8.2 没有新增游戏实机验收，不扩大 0.8.1 的实机验证结论。铺路实战恢复、其他机器与账号、不同赛季布局及长期运行仍需独立验证，见 [路线图](ROADMAP.md)。
